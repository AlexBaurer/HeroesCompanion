# ADR-0002: Записи игр — формат v1 в shared_preferences, миграция при первом запуске

Контекст: v1 хранит записи игр в `shared_preferences` под ключом `score_records` как список JSON-строк вида `{dateTime, playerScores: [{playerName, score, faction}]}`. У пользователей уже есть накопленные записи. Решение: v2 сохраняет этот формат без изменений и при первом запуске мигрирует существующие данные (если ключ v1 найден) в новую модель; перехода на SQLite/drift нет.

Причина: объём данных мал, а неизменный формат делает миграцию детерминированной и исключает потерю истории игр. Работает только при том же `applicationId`, что у установленной v1: v1 собрана с `com.example.heroescompanion` (из `output-metadata.json`), v2 создаётся с тем же идентификатором.
