# ADR-0001: Приложение — компаньон, а не движок игры

Контекст: v2 переписывается с нуля на основе правил из `docs/rules/`, которые описывают куда больше, чем отслеживает v1 (карта, чудовища, крепости, артефакты, здания, фракционные механики). Решение: v2 сопровождает партию — ведёт ресурсы, армию, раунды, порядок действий и подсчёт очков, но не проверяет правила и не моделирует игру целиком. Новые области отслеживания добавляются только как осознанные отдельные тикеты.

Причина: приложение должно оставаться быстрым инструментом у стола, а не вторым экземпляром игры; полное моделирование правил трёх коробок — это отдельный проект с иным качеством и рисками.
