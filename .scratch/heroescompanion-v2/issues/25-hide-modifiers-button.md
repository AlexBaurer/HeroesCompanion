# 25 — Убрать кнопку «Модификаторы силы» у фракций без модификаторов (кроме эльфов)

**What to build:** Кнопка «МОДИФИКАТОРЫ СИЛЫ» на экране партии показывается только тогда, когда фракции есть что показать в модалке: модификаторы силы юнитов или здание «Лавка бронника» (апгрейд). Сейчас кнопка видна всегда, и у фракции без модификаторов модалка открывается с пустой заглушкой «У фракции нет модификаторов».

- **Данные:**
  - В текущих данных фракция без модификаторов — одна: **Наги** (`nags.json` — нет поля `modifiers`, парсер даёт пустой список; `armyPower: nSquared`, без `battleUpgrade`). После изменения у Наг кнопка пропадает.
  - Эльфы (`elfs.json`) — единственная фракция с 0 модификаторов, но с `battleUpgrade` («Лавка бронника») — кнопка остаётся.
  - Остальные 16 фракций имеют ≥1 модификатор — для них кнопка не меняется.

- **UI (`lib/features/game/presentation/game_screen.dart`, `_GameView.build`):**
  - Кнопку «МОДИФИКАТОРЫ СИЛЫ» выводить только когда `faction.modifiers` не пуст **или** `faction.battleUpgrade != null`.
  - Заглушку «У фракции нет модификаторов» в `strength_modifiers_sheet.dart` не трогать: модалка — публичный виджет, её можно открыть из другого места.

- **Тесты (`test/features/game/game_screen_test.dart`):**
  - Добавить фикстуру Наг (индекс 5 в `FactionRepository.factionFiles`): имя «Наги», без `modifiers` и без `battleUpgrade` (можно взять из `nags.json`).
  - Наги — кнопки «МОДИФИКАТОРЫ СИЛЫ» нет.
  - Эльфы-фикстура «Лавка» (0 модификаторов + `battleUpgrade`) — кнопка есть.
  - Обычная фракция с модификаторами (фикстура «Тестовая») — кнопка есть (существующие тесты, открывающие модалку, остаются зелёными).

- Реальная фракция без модификаторов — Наги (`nags.json`, 0 модификаторов, без `battleUpgrade`): для них кнопка исчезает, и это реальное изменение поведения, а не только защита на будущее.
