# 03 — Доменный слой: сессия партии

**What to build:** Сессия партии как единый источник истины: раунд (1–16), ресурсы фракции, армия (общее число и «в бой» на каждый юнит, «в бой» не превышает общее), сила армии Σ(количество × сила юнита) с признаком особого расчёта в данных фракции (Наги — n² краков), порядок действий (5 действий, 4 выбраны с уровнями 1–4, одно пустое), состояния модификаторов (toggle — bool, counter — int). Сила юнита = базовая с применёнными модификаторами по цепочке.

**Blocked by:** 02

**Status:** done

- [x] Сила армии считается для обычной фракции и для Наги (n²)
- [x] «В бой» автоматически не превышает общее число (clamp при уменьшении)
- [x] Toggle и counter модификаторы применяются; «Майя 7→10→14» — включением первой и второй ступени
- [x] Раунд идёт 1→16; после 16-го партия завершается
- [x] Порядок действий: 4 из 5 с уровнями 1–4, невыбранное действие пустое
- [x] Состояние модификаторов не дублируется (один источник истины)
- [x] Юнит-тесты на силу армии, модификаторы и порядок действий
