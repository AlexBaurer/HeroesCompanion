# 16 — Сброс армии «в бой» на границе раунда

**What to build:** После нажатия кнопки «Следующий раунд» (экран партии, тикет 07) заявленные «в бой» армии сбрасываются в 0 — юниты, отправленные в бой в прошедшем ходу, вычитаются из общего войска.

- **Домен (сессия тикета 03):** `advanceRound()` (граница сражения) обнуляет заявленных «в бой» для всех юнитов фракции; ресурсы не трогаются. Сброс «в бой» дополняет уже существующий сброс «Лавки бронника» (тикет 11) на той же границе.
- **UI (экран партии тикета 07):** без изменений — кнопка «Следующий раунд» уже вызывает `advanceRound`, панель армии пересчитает «Сила в бой» в 0 и отнимет от общей армии количество юнитов "в бой".

**Blocked by:** 03, 07, 11

- [x] Общее число юнитов при сбросе меняются на количество юнитов "в бой"

## Comments

Поведение не из v1 (там «в бой» сохранялся между раундами, `_nextRound` только увеличивал раунд). Приложение не проверяет правила (ADR-0001), механика вводится по запросу. Граница сброса — та же, что у «Лавки бронника»: `advanceRound()`, единый источник истины партии.

Реализовано: `advanceRound()` в `GameSession` (`lib/domain/session.dart`) на границе сражения вычитает заявленных «в бой» юнитов из общего числа и обнуляет «в бой» для всех юнитов фракции; ресурсы не трогаются; сброс «Лавки бронника» остаётся на той же границе. UI не менялся — кнопка «Следующий раунд» уже вызывает `advanceRound`, панель армии читает сессию («Сила в бой» становится 0, «Сила армии» уменьшается на силу отправленных).

- **Домен**: цикл по `faction.units` через `setArmyTotal(id, total − deployed)` и `setArmyDeployed(id, 0)` (через сеттеры — с клампом и чисткой выбора «Лавки бронника»).
- **Тесты**: сессия — 3 новых (обнуление «в бой», вычитание из общего числа, ресурсы не трогаются) + обновлён эльфийский «новый раунд» (после сброса `deployedArmyStrength` 0, `totalArmyStrength` 0); виджет — новый тест «Следующий раунд обнуляет „в бой“ и вычитает из армии» + обновлён тест «Лавки бронника» (после раунда «Сила в бой: 0»). Проверено прогоном чистой Dart-логики домена локально (все проверки прошли, `dart analyze` домена чист); `flutter test` требует машины со SDK.
