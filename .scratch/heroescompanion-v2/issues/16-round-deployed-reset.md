# 16 — Сброс армии «в бой» на границе раунда

**What to build:** После нажатия кнопки «Следующий раунд» (экран партии, тикет 07) заявленные «в бой» армии сбрасываются в 0 — юниты, отправленные в бой в прошедшем ходу, вычитаются из общего войска.

- **Домен (сессия тикета 03):** `advanceRound()` (граница сражения) обнуляет заявленных «в бой» для всех юнитов фракции; ресурсы не трогаются. Сброс «в бой» дополняет уже существующий сброс «Лавки бронника» (тикет 11) на той же границе.
- **UI (экран партии тикета 07):** без изменений — кнопка «Следующий раунд» уже вызывает `advanceRound`, панель армии пересчитает «Сила в бой» в 0 и отнимет от общей армии количество юнитов "в бой".

**Blocked by:** 03, 07, 11

**Status:** ready-for-agent

- [ ] `advanceRound()` обнуляет «в бой» для всех юнитов фракции
- [ ] Общее число юнитов при сбросе меняются на количество юнитов "в бой"
- [ ] UI: после «Следующий раунд» «Сила в бой» становится 0
- [ ] Юнит-тесты: сброс «в бой», изменение общего числа

## Comments

Поведение не из v1 (там «в бой» сохранялся между раундами, `_nextRound` только увеличивал раунд). Приложение не проверяет правила (ADR-0001), механика вводится по запросу. Граница сброса — та же, что у «Лавки бронника»: `advanceRound()`, единый источник истины партии.
