# 23 — Экран партии Гриболюдов: по одному воину каждого типа, сетка 3×4 вместо крутилок

**What to build:** У Гриболюдов (тикет 07) не может быть больше одного воина каждого типа — счётчики «всего» и «в бой» (тикет 07, колёсики `ResourceCounterWheel` в `ArmyBlockPanel`) не имеют смысла. У фракции 12 разновидностей воинов. Заменить ленту юнитов с крутилками на сетку 3 ряда × 4 колонки с меньшими картинками: тап по картинке подсвечивает юнита и добавляет его силу «в бой», повторный тап снимает подсветку и силу.

- **Данные и домен:**
  - В `Faction` (и JSON фракции) — новый флаг «по одному воину каждого типа» (например `uniqueUnits`): у Гриболюдов `true`, у остальных `false` (поле опциональное, по умолчанию `false`). Парсер (`faction_parser.dart`) и контракт данных (`faction_data_test.dart`) дополняются.
  - `GameSession` для `uniqueUnits`-фракций: моделируется только заявка «в бой» — `0/1` на юнита, общего числа/наличия нет (у Гриболюдов доступность воинов не отслеживается в приложении). Новый метод (например `toggleDeployed(unitId)`): в бой `1` ↔ `0`; `setArmyTotal` для таких юнитов не применяется (в UI крутилок нет).
  - Сила: `deployedArmyStrength` = Σ `unitBattlePower` по заявленным «в бой» (каждый один раз). Общая сила армии (`totalArmyStrength`) для `uniqueUnits`-фракций не используется и не показывается.
  - Граница раунда (`advanceRound`): для `uniqueUnits` «в бой» сбрасывается (юниты отзываются из боя), армия не потребляется; общее число не участвует (сейчас `_resetDeployedArmy` вычитает отправленных из общего числа).
  - Модификаторы не меняются: toggle-модификаторы Гриболюдов (`+4` к силе Шляпника/Грибового/Лисидера) применяются через `unitPower`/`unitBattlePower` как раньше.
- **UI (`ArmyBlockPanel` в `lib/features/game/presentation/widgets/army_block_panel.dart`):**
  - Для `uniqueUnits`-фракций вместо горизонтальной ленты с колёсиками — сетка 3 колонки × 4 ряда (`GridView.count`/`Wrap`) на 12 юнитов в порядке данных фракции. Картинки юнитов меньше (ассет `assets/units/<id>.PNG`, тот же `errorBuilder` — серая плашка с именем; папка пока пустая), подпись имени.
  - Карточка юнита: тап → подсветка (рамка/оверлей цветом фракции из `colorFromHex`, можно галочку) и «в бой» = 1; повторный тап → подсветка и «в бой» убираются. Одновременно можно выбрать несколько юнитов (нет ограничения, кроме 12).
  - Бейджи сверху: у Гриболюдов остаётся только «Сила в бой: N», бейдж «Сила армии: N» не показывается (общей силы армии у фракции нет в этом экране). Высота панели при необходимости корректируется под 4 ряда.
  - Остальные фракции — текущая лента с крутилками, без изменений.
- **Тесты:**
  - Домен/сессия: toggle «в бой» 0/1; сила в бой = Σ по заявленным; общая сила армии не участвует; граница раунда отзывает «в бой» без потребления; toggle-модификаторы продолжают менять силу в бой.
  - Парсер/контракт данных: новый флаг у Гриболюдов, отсутствует/по умолчанию у остальных.
  - Виджет (`game_screen_test.dart`): у Гриболюдов сетка 3×4 без крутилок и без бейджа «Сила армии»; тап подсвечивает и добавляет силу «в бой», повторный тап убирает; бейдж «Сила в бой» обновляется; у других фракций лента с крутилками как раньше.
