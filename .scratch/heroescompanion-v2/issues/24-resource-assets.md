# 24 — Ассеты фракционных ресурсов Гриболюдов и Оборотней; убрать «Подковы» у Циклопов

**What to build:** Фракционные ресурсы коробки 3 получают фоновые иконки (как у Дерева/Железа/Золота/Ярости), а у Циклопов убирается несуществующий ресурс «Подковы». Иконки подключаются через `resourceIconPaths` — сами файлы ассетов готовит пользователь.

- **Данные:**
  - `assets/factions/mushroomers.json`: ресурс «Грибной ресурс» остаётся и получает иконку `assets/build.PNG`.
  - `assets/factions/werewolves.json`: ресурс «Мясо» остаётся и получает иконку `assets/meat.PNG` (файл уже лежит на компе сборки, рабочая папка `heroescompanion_v3`).
  - `assets/factions/cyclops.json`: из `resources` убрать «Подковы» → остаётся `["Дерево", "Железо", "Золото"]`. Описание фракции «Подковы» не упоминает — править не нужно.
- **UI (`lib/features/game/presentation/widgets/resource_counter_wheel.dart`, карта `resourceIconPaths`):**
  - Добавить `'Грибной ресурс': 'assets/build.PNG'` и `'Мясо': 'assets/meat.PNG'`.
  - После этого под колёсиками этих ресурсов перестаёт показываться текстовая подпись-название (`game_screen.dart` выводит её только когда `resourceIconPaths[resource] == null`).
- **Глоссарий (`CONTEXT.md`):** в строке про уникальные фракционные ресурсы убрать «подковы».
- **Тесты:**
  - `test/domain/faction_data_test.dart`: тест Циклопов перестаёт ожидать «Подковы» — проверять, что ресурса нет (ресурсы ровно `["Дерево", "Железо", "Золото"]`); у Гриболюдов и Оборотней фракционные ресурсы на месте.
  - `test/features/game/game_screen_test.dart`: у Гриболюдов «Грибной ресурс» больше не подписывается названием (иконка задана); при добавлении фикстуры Оборотней/Циклопов в фейковый репозиторий — «Мясо» с иконкой, «Подков» нет.
