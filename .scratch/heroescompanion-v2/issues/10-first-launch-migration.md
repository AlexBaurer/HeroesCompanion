# 10 — Миграция записей v1 при первом запуске

**What to build:** При первом запуске v2 на устройстве с установленной v1: чтение ключа `score_records` из shared_preferences (формат v1, тот же applicationId — ADR-0002), преобразование через кодек из тикета 04, сохранение в хранилище v2, установка флага «миграция выполнена» — повторно не запускается. Перенесённые записи появляются в истории.

**Blocked by:** 04, 09

**Status:** done

- [x] Сымитированные данные v1 переносятся и видны в истории
- [x] Повторный запуск не дублирует записи
- [x] Отсутствие данных v1 не ломает первый запуск

## Comments

Реализовано в `lib/features/scores/data/game_record_migration.dart` (GameRecordMigration: `migrateIfNeeded` — при первом запуске читает ключ `score_records` (формат v1, тот же applicationId — ADR-0002), преобразует через кодек тикета 04 (`decodeAll` — пропуск битых записей) и сохраняет обратно в том же ключе и формате v1 (нормализация, байт-в-байт для валидных записей), после чего ставит флаг `score_records_migrated` — повторно не запускается; идемпотентна даже без флага). Запуск — в `main.dart` до `runApp`: `SharedPreferences.getInstance()` → миграция → старт; при сбое миграции приложение всё равно запускается (миграция повторится при следующем запуске). Триггер в `main`, а не в провайдере истории, чтобы перенос происходил именно при первой партии, независимо от навигации. Интерфейс хранилища расширен под флаг: `StringListPreferences` → `Preferences` (`getBool`/`setBool`), адаптер переименован в `SharedPreferencesAdapter`, тестовый фейк — `test/helpers/fake_preferences.dart` (FakePreferences). Тесты: `test/features/scores/data/game_record_migration_test.dart` (7 тестов: перенос и чтение хранилищем, флаг, байт-в-байт формат v1, битые записи, отсутствие данных, повторный запуск с флагом и без — идемпотентность) и виджет-тест в `score_history_screen_test.dart` («записи v1 после миграции первой партии видны в истории»). Общий фикстур строки v1 — `test/helpers/v1_records.dart`. Проверено прогоном в изолированном чистом Dart-пакете (анализ чист, 13/13 проверок), требуют финального прогона `flutter test` на машине со SDK.
