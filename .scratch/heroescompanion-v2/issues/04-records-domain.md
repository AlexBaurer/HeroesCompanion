# 04 — Доменный слой: записи игр и миграция

**What to build:** Кодек записей игр в формате v1: `ScoreRecord` (дата, 1–4 игрока) и `PlayerScore` (имя, очки, фракция) — сериализация/десериализация round-trip в тот же JSON, что писала v1 (`score_records`: список строк с `dateTime` и `playerScores`). Преобразование старых записей v1 в модель v2: идемпотентно (повторный прогон не дублирует), устойчиво к битым записям (пропуск, не краш).

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Round-trip: запись → JSON → запись идентична
- [ ] JSON-формат совпадает с v1 (dateTime ISO-8601, playerScores: playerName/score/faction)
- [ ] Преобразование v1→v2 для валидных, частично битых и пустых данных
- [ ] Повторное преобразование не дублирует записи
- [ ] Юнит-тесты: round-trip, битые данные, идемпотентность
