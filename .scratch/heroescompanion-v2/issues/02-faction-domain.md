# 02 — Доменный слой: модель фракции и парсер JSON

**What to build:** Модели домена: `Faction` (имя, часть игры, цвет, фон, ресурсы, юниты), `Unit` (имя, базовая сила), `StrengthModifier` двух типов — `Toggle` (включён → бонусная сила) и `Counter` (базовая + счёт × шаг), каждый с явной привязкой к юниту. Парсер и валидатор JSON фракции: известные поля, силы-числа, модификаторы ссылаются только на существующих юнитов, понятные типизированные ошибки.
