# 15 — Фиксация ориентации экрана (портрет) при повороте устройства

**What to build:** Приложение не должно менять ориентацию при повороте устройства: все экраны (главное меню, выбор фракции, партия, ввод очков, история) остаются в портретной ориентации независимо от положения устройства.

**Status:** done

- [x] Поворот устройства не меняет ориентацию ни на одном экране
- [x] Приложение запускается и остаётся в портретной ориентации
- [ ] Проверено на устройстве

## Comments

От пользователя: приложение не должно менять ротацию при повороте устройства.

Технический контекст:

- Цель — Android (папки `ios/` в репо нет; весь код — платформенно-нейтральный).
- В манифесте (`android/app/src/main/AndroidManifest.xml`) у activity уже есть `android:configChanges="orientation|...|screenSize|smallestScreenSize|..."` — activity при повороте не пересоздаётся, но UI Flutter всё равно перекомпонуется в альбомную ориентацию.
- Варианты реализации (можно в комбинации): (а) `android:screenOrientation="portrait"` у activity в манифесте — блокировка на уровне системы; (б) `SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp])` в Dart при старте (`main()` или загрузка `HeroesCompanionApp`) — блокировка на уровне Flutter. Плюс (б) — остаётся единым с кодом; минус — срабатывает после стартовой загрузки, поэтому обычно рекомендуют оба.
- У v1 папки `android/` в репо не было — прецедента фиксации ориентации нет; референс — желаемое поведение пользователя, а не v1.
- Проверка — на устройстве (прогон у пользователя, как остальной UI): запуск в альбомной ориентации устройства и поворот на каждом экране.

Реализация:

- Оба механизма из тикета: (а) `android:screenOrientation="portrait"` у activity в манифесте — блокировка на уровне системы, работает и до старта Flutter; (б) `lockPortraitOrientation()` в `lib/app/orientation_lock.dart` — `SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp])`, вызывается в `main()` сразу после `ensureInitialized()`.
- Блокировка глобальная — действует на всех экранах (главное меню, выбор фракции, партия, ввод очков, история) и на стартовую загрузку.
- Тест: мок канала `flutter/platform` проверяет, что Flutter получает запрос только на `DeviceOrientation.portraitUp` (`test/app/orientation_lock_test.dart`). Прогон тестов — на Flutter-компе.
- Проверка на устройстве — остаётся открытой (чекбокс выше).
