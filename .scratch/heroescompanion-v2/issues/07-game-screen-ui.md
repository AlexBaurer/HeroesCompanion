# 07 — UI: экран партии

**What to build:** Экран партии поверх сессии из тикета 03: фон фракции, панель армии (изображения юнитов, счётчики «всего» и «в бой», сила армии и сила в бой), ресурсы-колёсики с иконками, текущий раунд и кнопка «Следующий раунд» (после 16-го — «Закончить игру»), порядок действий (4 из 5 с уровнями 1–4), модальное окно модификаторов силы. Выход — только двойным нажатием «назад». Завершение партии ведёт на экран ввода очков с фракцией игрока.

**Blocked by:** 03, 05, 06

**Status:** ready-for-agent

- [ ] Все элементы партии отображаются и обновляются из сессии
- [ ] Сила армии пересчитывается при изменении счётчиков и модификаторов
- [ ] Модалка модификаторов читает единый источник истины; закрытие не теряет состояние
- [ ] Выход только двойным «назад»
- [ ] После 16-го раунда «Закончить игру» ведёт на ввод очков с фракцией игрока
