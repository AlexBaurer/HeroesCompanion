# 07 — UI: экран партии

**What to build:** Экран партии поверх сессии из тикета 03: фон фракции, панель армии (изображения юнитов, счётчики «всего» и «в бой», сила армии и сила в бой), ресурсы-колёсики с иконками, текущий раунд и кнопка «Следующий раунд» (после 16-го — «Закончить игру»), порядок действий (4 из 5 с уровнями 1–4), модальное окно модификаторов силы. Выход — только двойным нажатием «назад». Завершение партии ведёт на экран ввода очков с фракцией игрока.

**Blocked by:** 03, 05, 06

**Status:** ready-for-agent

- [x] Все элементы партии отображаются и обновляются из сессии
- [x] Сила армии пересчитывается при изменении счётчиков и модификаторов
- [x] Модалка модификаторов читает единый источник истины; закрытие не теряет состояние
- [x] Выход только двойным «назад»
- [x] После 16-го раунда «Закончить игру» ведёт на ввод очков с фракцией игрока

## Comments

Реализовано в `lib/features/game/`: `data/game_session_provider.dart` (GameSessionNotifier — провайдер сессии, мутации уведомляют через `ref.notifyListeners`), `presentation/game_screen.dart` (фон фракции, раунд 1–16, двойное «назад» через PopScope, «Закончить игру» → `/score?faction=…`), `presentation/widgets/` (ArmyBlockPanel с счётчиками «всего»/«в бой» и силой армии, ResourceCounterWheel, ActionOrderPanel — перестановка 4 из 5 с уровнями 1–4, StrengthModifiersSheet — модалка читает сессию напрямую). Пути изображений юнитов — `assets/units/<id>.PNG`, иконки ресурсов/действий — как в v1 (`assets/wood.PNG` и т.д.), с fallback при отсутствии ассета. Тесты: `test/features/game/game_session_provider_test.dart` (провайдер), `test/features/game/game_screen_test.dart` (виджеты: элементы, сила, раунд, модалка, двойное «назад»). На этой машине нет Flutter SDK — тесты требуют прогона `flutter test` на машине со SDK.
