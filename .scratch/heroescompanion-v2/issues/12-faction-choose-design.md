# 12 — UI: редизайн экрана выбора фракции

**What to build:** Полноширинный бесшовный список всех 18 фракций: плитка — фон-изображение фракции из ассетов (путь `backgroundPath` из данных, как в v1), поверх — имя фракции с обводкой краёв букв. Без заголовков «Часть N», без отступов, скруглений и разделителей между плитками. Иммерсивный AppBar. Тап по плитке — сразу переход на экран партии.

**Status:** ready-for-agent

**Дизайн (гриль с пользователем, раунды 1–2):**

- Границы: только экран выбора фракции (главное меню не трогаем).
- Структура: один скролл, все 18 фракций подряд в порядке каталога (части 1→3); секции-заголовки не нужны.
- Плитка: на всю ширину экрана, высота ~120dp (пользователь потестирует, высота может поменяться); между плитками нет отступов, скруглений и разделителей — даже если соседние фоны визуально сливаются.
- Содержимое плитки: фон — `backgroundPath` фракции из JSON (cover); имя фракции — слева, по вертикали по центру, крупно (18–20sp, bold), обводка краёв букв (в Flutter — 4-сторонние тени у TextStyle, нативного stroke нет).
- Fallback без ассетов: сплошной цвет фракции (`colorFromHex`) + имя (errorBuilder у Image.asset).
- AppBar: иммерсивный (`extendBodyBehindAppBar`), полупрозрачный; заголовок — с той же обводкой текста; кнопка «назад» — с полупрозрачной подложкой.
- Тап: сразу открывать экран партии (превью-лист не нужен — v1-парати, экран партии в тикете 07 покажет юнитов).
- Ассеты: файлы по путям из JSON пользователь подготовит вручную (в т.ч. переименует под пути).

**Blocked by:** 06 (экран-заглушка реализован и работает; редизайн — поверх)

- [ ] Плитки на всю ширину, без отступов/скруглений/разделителей

- [ ] Имя фракции слева по центру с обводкой краёв букв
- [ ] Иммерсивный AppBar (extendBodyBehindAppBar, подложка у «назад»)
- [ ] Тап открывает экран партии с выбранной фракцией
- [ ] Экран выглядит приемлемо без ассетов (fallback-цвета)
