# 19 — UI: окно фракции с описанием перед переходом в игру

**What to build:** При выборе фракции на экране выбора (тикет 12) тап по плитке больше не ведёт сразу на экран партии — открывается окно фракции: полноэкранная страница с фоном фракции (как плитка), именем фракции и кратким описанием фракции (2–3 предложения). В окне — кнопка «Начать игру», которая ведёт на экран партии (тикет 07) с выбранной фракцией. Системное «назад» из окна возвращает на экран выбора фракции.

- **Данные (JSON, все 18 фракций):** новое поле `description` — краткое описание фракции (2–3 предложения, на русском). Агент чернит тексты по `docs/rules/rules1-3.pdf`, пользователь вычитывает (конвенция тикета 05).
- **Домен (тикет 02):** `Faction.description` (String, непустой); парсер читает `description` как обязательное поле — отсутствие или пустая строка дают понятную ошибку в стиле существующих.
- **UI:** новый экран-маршрут (go_router) окна фракции: фон — `backgroundPath` фракции (cover, fallback — сплошной цвет как в тикете 12), имя фракции (крупно, обводка краёв букв — как плитка), описание (скроллится, если не помещается), кнопка «Начать игру» (акцентная, по теме). Без AppBar (стиль тикетов 17/18). Тап по плитке → окно фракции; «Начать игру» → экран партии с этой фракцией; системное «назад» → экран выбора фракции.

## Comments

Реализовано:

- **Данные**: во все 18 `assets/factions/*.json` добавлено поле `description` (черновик по `docs/rules/rules1-3.pdf` — официальные однострочники коробок + второй предложение из правил механик; требует вычитки пользователем).
- **Домен (тикет 02)**: `lib/domain/faction.dart` — `Faction.description` (String, обязательное); `lib/domain/faction_parser.dart` — `description` в `_factionFields` и читается `_readNonEmptyString` (отсутствие → `FactionMissingFieldException`, пустая/не строка → `FactionInvalidValueException`).
- **UI**: новый `lib/features/main_menu/presentation/faction_preview_screen.dart` — окно фракции: полноэкранный фон (`backgroundPath` cover, fallback — сплошной цвет `colorFromHex`), имя с обводкой краёв букв (переиспользован `FactionChooseScreen.strokedTextStyle`), скроллируемое описание на полупрозрачной панели, кнопка «Начать игру» (акцентная — цвет фракции). Без AppBar. Маршрут `/faction_preview/:factionName` в `lib/app/app_router.dart`. Плитка (тикет 12) теперь ведёт на окно; «Начать игру» в окне — `context.pushReplacement('/faction/<имя>')` — экран партии (тикет 07), окно уходит из стека, «назад» из партии возвращает на выбор фракции.
- **Тесты**: юнит — парсинг `description` (валидное, отсутствует, пустое, не строка) в `faction_parser_test.dart`; контракт данных — непустое описание во всех 18 JSON в `faction_data_test.dart`; виджет — новый `faction_preview_screen_test.dart` (плитка → окно, фон/имя/описание, «Начать игру» → партия, системное «назад» → выбор фракции). Обновлены переходы в `faction_choose_screen_test.dart`, `game_screen_test.dart` (переход через окно), `smoke_test.dart`. Все JSON-фикстуры тестов дополнены `description`.

Проверено на этой машине (чистый Dart): `dart analyze lib/domain` чист; `dart run tool/validate_factions.dart` и `dart run tool/verify_faction_catalog.dart` — OK; все 18 JSON валидны (json.load + непустой description).
