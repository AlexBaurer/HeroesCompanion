# 14 — UI: доработка экрана истории игр

**What to build:** Доводка экрана «История игр» (тикет 09) по результатам прогона на устройстве: причесать дизайн, добавить удаление отдельных записей и выбор сортировки истории.

**Status:** needs-triage

- [x] Приятный дизайн экрана (карточки, отступы, пустое состояние) — причесаны текущие карточки-раскрытия: итог и дата в заголовке, кнопка удаления, вращающаяся стрелка раскрытия
- [x] Удаление отдельной записи (с подтверждением) — кнопка на карточке + диалог; хранилище: `StoredGameRecord` (позиция записи) и `removeAt`
- [x] Сортировки (по дате возр./убыв., по сумме очков) — меню сортировки в AppBar, компараторы в домене (`HistorySort`)

**Blocked by:** 09

## Comments

От пользователя (после прогона):

1. Дизайн поприятнее — направление не определено: причесать текущие карточки (отступы, типы, цвета) или сделать новый макет. Нужен гриль с пользователем перед реализацией.
2. Удаление каждой записи отдельно — сейчас есть только очистка всей истории; нужна кнопка удаления на карточке записи с диалогом подтверждения (или swipe). Понадобится удаление по индексу/ключу в хранилище: сейчас у `GameRecordStorage` только `add`/`loadAll`/`clear`.
3. Сортировки — сейчас история всегда «новые сверху» (`scoreHistoryProvider` фиксированная сортировка); нужен выбор (по дате, по сумме очков; направление).

Реализация (гриль с пользователем перед тикетом):

- Направление дизайна — причесать текущие карточки-раскрытия (не новый макет); пустое состояние и очистка истории без изменений.
- Удаление — кнопка с иконкой на карточке + диалог подтверждения (не swipe).
- Сортировка — меню в AppBar: по дате (новые/старые сверху), по сумме очков игроков записи (больше/меньше сверху); по умолчанию — новые сверху, как в тикете 09. Сортировка — состояние экрана, `scoreHistoryProvider` отдаёт записи в порядке записи.
- Хранилище: `loadAll` возвращает записи с позицией (`StoredGameRecord`, позиция среди читаемых записей — битые строки v1 пропускаются, как при чтении); `removeAt(index)` удаляет запись по этой позиции, битые строки не трогает.
