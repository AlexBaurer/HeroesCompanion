# 14 — UI: доработка экрана истории игр

**What to build:** Доводка экрана «История игр» (тикет 09) по результатам прогона на устройстве: причесать дизайн, добавить удаление отдельных записей и выбор сортировки истории.

**Status:** needs-triage

- [ ] Приятный дизайн экрана (карточки, отступы, пустое состояние)
- [ ] Удаление отдельной записи (с подтверждением)
- [ ] Сортировки (напр., по дате возр./убыв., по сумме очков)

**Blocked by:** 09

## Comments

От пользователя (после прогона):

1. Дизайн поприятнее — направление не определено: причесать текущие карточки (отступы, типы, цвета) или сделать новый макет. Нужен гриль с пользователем перед реализацией.
2. Удаление каждой записи отдельно — сейчас есть только очистка всей истории; нужна кнопка удаления на карточке записи с диалогом подтверждения (или swipe). Понадобится удаление по индексу/ключу в хранилище: сейчас у `GameRecordStorage` только `add`/`loadAll`/`clear`.
3. Сортировки — сейчас история всегда «новые сверху» (`scoreHistoryProvider` фиксированная сортировка); нужен выбор (по дате, по сумме очков; направление).
